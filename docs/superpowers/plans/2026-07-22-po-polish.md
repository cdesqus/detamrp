# Supplier Order Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Modernize the PO PDF, add accessible colored PO status badges, and expose the read-only Sage PO Number consistently.

**Architecture:** Keep existing purchase-order APIs and PDF endpoints. Add presentation helpers on the frontend and refactor only the PO renderer layout, preserving tenant, permission, Unicode, and export protections.

**Tech Stack:** Go 1.26, go-pdf/fpdf, Next.js 16, React 19, TypeScript, Go tests, Vitest.

## Global Constraints

- UI remains compact and color is never the only status signal.
- `sagePurchaseOrderNumber` is read-only and may remain empty.
- Existing PDF authorization, Unicode fonts, in-memory rendering, `private, no-store`, and price redaction remain unchanged.
- No new API writes or manual Sage-number workflow.
